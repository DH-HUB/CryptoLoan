= Tests et vérifications

Cette page présente les principales vérifications automatisées et techniques
effectuées sur l'application CryptoLoan.
Les tests backend sont exécutés avec Maven et couvrent notamment les cas
d'usage métier, les contrôleurs REST et les règles d'architecture.
